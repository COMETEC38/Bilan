# COMETEC Bilan

Traitement des bilans pour débitmètres portables **BUL'R2** (COMETEC – instrumentation des eaux).

Application : **https://cometec38.github.io/Bilan/**

- Ouvrez l'adresse dans Edge ou Chrome, puis cliquez sur « Installer l'application » pour l'avoir sur votre PC.
- Les fichiers des bilans sont traités sur votre ordinateur et ne sont envoyés nulle part.
- L'application installée se met à jour toute seule à l'ouverture, dès qu'une connexion Internet est disponible.

Version de test interne COMETEC.
